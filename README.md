# KiCad Мастер Pro

Интерактивный курс проектирования печатных плат в KiCad 8–10: статический сайт (PWA) и serverless API для Vercel.

## Развёртывание на Vercel

1. **Импорт репозитория.** На [vercel.com/new](https://vercel.com/new) выберите репозиторий `Makarych12/KiCad`. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми: сайт статический, функции лежат в `api/`.
2. **Хранилище.** Project → Storage → Marketplace → **Upstash Redis** (это бывший Vercel KV) → Connect к проекту. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
3. **AI-ассистент.** Project → Settings → Environment Variables → `ANTHROPIC_API_KEY` (ключ с console.anthropic.com). Необязательно, без ключа сайт работает.
4. **Deploy** или Redeploy после добавления переменных. Каждый следующий `git push` в `main` деплоится автоматически.
5. **Проверка.** Откройте `https://<ваш-проект>.vercel.app/api/health`. Должно быть `"storage":"redis"` и, если задан ключ, `"ai":true`.

Все переменные описаны в `.env.example`. Если Redis не подключён, API работает, но данные живут только в памяти функции и пропадают при перезапуске. Статус «хранилище в памяти» виден в Настройках сайта.

### API (`api/*.js`, общий код — `lib/`)

| Эндпоинт | Методы | Назначение |
|---|---|---|
| `/api/chat` | POST | AI-ассистент (Claude, потоковый ответ SSE) |
| `/api/messages` | GET `?since=`, POST | Чат сообщества (опрос раз в 4 с) |
| `/api/leaderboard` | GET, POST | Таблица лидеров |
| `/api/submit-project` | GET, POST, POST `?action=rate&id=` | Галерея проектов и рейтинг |
| `/api/file` | GET `?id=&kind=` | Скачивание файлов галереи |
| `/api/sync` | GET, PUT | Синхронизация прогресса |
| `/api/register` | GET, POST | Вход по нику (токен) |
| `/api/newsletter` | POST | Подписка на рассылку |
| `/api/health` | GET | Состояние (AI, тип хранилища) |

У всех эндпоинтов CORS: по умолчанию `*`, ограничить можно через `ALLOWED_ORIGIN`. Лимиты частоты считаются в Redis.

## Локальный запуск

```bash
npm install
npm run dev                      # http://localhost:8080 — статика + те же функции из api/
ANTHROPIC_API_KEY=sk-ant-... npm run dev
npm run test:api                 # тест всех эндпоинтов: с имитацией Upstash Redis и с локальным хранилищем
```

Локально без Redis данные сохраняются в `.data/db.json`. Переменные можно положить в `.env`: сервер прочитает его сам.

## Как обновлять

- **Схемы и проекты KiCad:** правьте `tools/circuits.py` / `tools/projects.py`, затем выполните `python3 tools/build.py`. Скрипт генерирует проекты, прогоняет ERC в `kicad-cli`, сверяет netlist с задуманными цепями, экспортирует SVG/PDF/BOM и обновляет `data/kicad-gen.js`. Нужен установленный KiCad 8+.
- **После любых изменений файлов:** выполните `python3 tools/make_sw.py`. Он обновит версию офлайн-кэша и `assets.json`.
- **Настоящие скриншоты KiCad:** положите PNG в `media/screens/` и пропишите их в `KM.data.screens` (`data/figures.js`). Аннотации наложатся поверх.
- **Настоящие видео:** положите mp4 в `media/videos/` и добавьте демо поле `video: 'media/videos/имя.mp4'`.

## Ограничения, о которых стоит знать

- Иллюстрации интерфейса — схематичные SVG-перерисовки окон KiCad, а не скриншоты. Реальный рендер KiCad есть только у схем-шаблонов и проектов.
- Изображения компонентов тоже схематичные, цены ориентировочные. Ссылки ведут на поиск у поставщиков и в базах даташитов.
- Схемы оформлены «метками цепей» (у каждого вывода — провод и имя цепи). Это полноценные схемы, но выглядят иначе, чем нарисованные вручную.
- Для плат (`.kicad_pcb`), Gerber и 3D-моделей нужна разводка человеком. В проектах есть схема, BOM и netlist, а плата делается командой F8 по урокам.
- Вход упрощённый (ник + токен), модерации чата нет. Для открытого публичного сайта стоит добавить настоящую аутентификацию и модерацию.
- Файлы галереи хранятся в Redis, поэтому лимит — 700 КБ на файл. Для больших архивов лучше подключить Vercel Blob.
- Чат обновляется опросом раз в 4 секунды: serverless-функции не держат постоянных соединений.
- Учебные тексты — только на русском, переводится интерфейс.
