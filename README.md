# KiCad Мастер Pro

Интерактивный курс проектирования печатных плат в KiCad 8–10. Статический сайт (PWA) и необязательный сервер для онлайн-функций.

## Запуск

**Проще всего:** через сервер курса. Он раздаёт сайт и включает чат, таблицу лидеров, синхронизацию, галерею и AI-ассистента:

```bash
cd server
npm install                               # один раз: SDK Anthropic для AI-ассистента
ANTHROPIC_API_KEY=sk-ant-... node server.mjs   # ключ не обязателен: без него AI выключен
# открыть http://localhost:8080
```

**Без сервера:** подойдёт любой статический хостинг или `python3 -m http.server` в корне. Уроки, практика, симулятор, компоненты, шаблоны, справочник, прогресс и офлайн-режим работают полностью. `index.html` открывается и как файл, но тогда не работают офлайн-кэш (service worker) и онлайн-функции.

## Как обновлять

- **Схемы и проекты KiCad:** правьте `tools/circuits.py` / `tools/projects.py`, затем выполните `python3 tools/build.py`. Скрипт генерирует проекты, прогоняет ERC в `kicad-cli`, сверяет netlist с задуманными цепями, экспортирует SVG/PDF/BOM и обновляет `data/kicad-gen.js`. Нужен установленный KiCad 8+.
- **После любых изменений файлов:** выполните `python3 tools/make_sw.py`. Он обновит версию офлайн-кэша и `assets.json`.
- **Настоящие скриншоты KiCad:** положите PNG в `media/screens/` и пропишите их в `KM.data.screens` (`data/figures.js`). Аннотации наложатся поверх.
- **Настоящие видео:** положите mp4 в `media/videos/` и добавьте демо поле `video: 'media/videos/имя.mp4'`.

## Ограничения, о которых стоит знать

- Иллюстрации интерфейса — схематичные SVG-перерисовки окон KiCad, а не скриншоты. Реальный рендер KiCad есть только у схем-шаблонов и проектов.
- Изображения компонентов тоже схематичные, цены ориентировочные. Ссылки ведут на поиск у поставщиков и в базах даташитов.
- Схемы оформлены «метками цепей» (у каждого вывода — провод и имя цепи). Это полноценные схемы, но выглядят иначе, чем нарисованные вручную.
- Для плат (`.kicad_pcb`), Gerber и 3D-моделей нужна разводка человеком. В проектах есть схема, BOM и netlist, а плата делается командой F8 по урокам.
- Авторизация на сервере упрощённая (ник + токен), без модерации. Подходит для домашнего и учебного использования. Для публичного сервера нужны настоящая аутентификация и HTTPS.
- Учебные тексты — только на русском, переводится интерфейс.
